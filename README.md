# AI-language-conversation
AI-powered Japanese conversation practice platform for Chinese learners.
## Project Overview
这个项目是一个面向中文日本语学习者的AI日常对话练习用网站，可以对使用者的对话以专业角度进行纠错以及反馈并评估提升
## Target users
在日常生活，留学，求职等一些日常场景下，希望提高自己的日语会话能力更加接近母语者的中文日语学习者
## Problems
- 和真人练习时容易紧张
- 不知道自己的表达是否自然
- 难以针对面试、学校和日常生活场景反复练习
## Why Not Ordinary ChatGPT?
- 与GPT直接对话无法专注在某个场景下，并且需要更专业的语言知识反馈
- 专门分析中国学习者常见的日语表达问题
- 模拟日本求职、学校、打电话等具体场景
- 不只是聊天，还会提供自然度、礼貌程度和语用反馈
- 保存多次练习结果，观察学习者的变化
- 为 WTC 或日语语用能力研究提供实验数据
## MVP Featrues
- AI 日语对话
- 日语表达反馈
- 对话记录
## Initial Practice Scenarios
- 想要打电话预约餐厅
- 马上要找自己的教授针对自己的研究计划书进行一个简单的介绍
- 求职面试前想要提前进行练习
